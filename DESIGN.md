# Design

Mode: Operate / Read. A Chinese-first thinking workspace for conversation, file reading and visual creation. Default daylight palette: soft mineral white, green ink and muted olive. The conversation and composer take priority; no marketing hero, gradient, oversized decoration or icon-tile grid.

Desktop: 254px sidebar, persistent workspace header, centered reading column and anchored composer. Mobile: overlay navigation, 44px primary controls, scrollable conversation, full-width composer. Light and dark palettes share semantic variables. Icons use a single authored SVG stroke family. Body text uses the user's Chinese UI fonts; code uses monospace. Reduced motion is respected. Authentication is a focused dialog. Guest/privacy, saving failure and quota states remain visible.
